**Khataflow**
--
Khataflow is a lightweight, modern invoicing and expense tracking tool built for freelancers, small businesses, and individuals who want simple financial management without the clutter.

-Track expenses & income

-Generate PDF invoices instantly

-View real-time reports & analytics

-Secure & private — your data stays with you

-Fast, minimal, and mobile-friendly


**Features**
--
Dashboard Overview: Get a quick snapshot of income, expenses, and balance.

Smart Invoicing: Create, share, and download invoices in seconds (with UPI/QR support if in India).

Expense Categories: Organize spending with customizable tags.

Recurring Entries: Automate repetitive invoices or expenses.

Data Export: Export to PDF, CSV, or Excel.

Dark/Light Mode for better usability.


**Tech Stack**
--
Frontend: React / Next.js (with Tailwind CSS for sleek UI)


**Working on**
--
Backend: Node.js + Express

Database: MongoDB (Mongoose ORM)

PDF Generation: pdfmake / jsPDF

Authentication: JWT-based secure login
